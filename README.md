# Neon Foundry

A browser-based cyberpunk idle factory game.

Build automated production lines, refine resources, upgrade your machines, and reboot the factory to unlock permanent production bonuses.

## Current MVP

- Passive Scrap production
- Alloy refining
- Machine upgrades
- Prestige / Reboot system
- Offline earnings
- Local save persistence
- Neon cyberpunk UI

## Development

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
```
